---

## 建立步驟（圖形介面）

1. 開啟「工作排程器」→ 左側「工作排程器程式庫」→「建立工作」。
2. **一般**頁籤：
   - 名稱：例如 `JackBot_position_change`
   - 勾選「以最高權限執行」
3. **觸發程序**頁籤 → 新增：
   - 每天 → 勾選「重複工作間隔」→ 選 **30 分鐘**（或 15 / 60 分鐘）
   - 持續時間：**無限期**
4. **動作**頁籤 → 新增：
   - 程式：`C:\Path\To\加密貨幣推播工具\.venv\Scripts\python.exe`
   - 引數：`jackbot.py position_change`（其他工作換指令名稱即可）
   - 開始於：`C:\Path\To\加密貨幣推播工具`
5. 對每個模組重複以上步驟。

## 環境變數設定

工作排程器預設**不讀取**你登入時的 PowerShell 環境變數，選一種方式：

**方法 A（推薦）：系統環境變數**
「控制台」→「系統」→「進階系統設定」→「環境變數」→ 在「系統變數」新增
`TG_TOKEN`、`CHAT_ID`、`CG_API_KEY` 等。

**方法 B：使用 bat 檔**（見 `run-one.example.bat`）
在 bat 內用 `set VAR=值` 設定後再呼叫 Python，工作排程器呼叫此 bat 即可。
⚠️ **勿把含真金鑰的 bat 提交到 Git 或分享給他人。**

## 快速驗證（執行前先測一次）

在 PowerShell 或 CMD（先 `cd 到專案目錄`，並已 `activate` 或用全路徑 Python）：

```powershell
.\.venv\Scripts\python.exe jackbot.py position_change
.\.venv\Scripts\python.exe jackbot.py hyperliquid
.\.venv\Scripts\python.exe jackbot.py crit_radar
```

看到 TG 推播就代表成功。
