# Windows 工作排程器：本機定時執行 JackBot

以下對應你目前的間隔：

- `position_change`：**每 30 分鐘**
- `hyperliquid`：**每 30 分鐘**
- `crit_radar`：**每 15 分鐘**

## 建議做法（圖形介面）

1. 開啟「工作排程器」→「建立工作」。
2. **一般**：勾選「以最高權限執行」（若需要存取網路磁碟再視情況調整）。
3. **觸發程序**：
   - 新增「依排程」→ **每天** → 重複工作間隔選 **30 分鐘**（持倉與巨鯨）或 **15 分鐘**（爆擊），持續時間選 **無限期**。
4. **動作**：
   - 程式：`C:\Path\To\加密貨幣推播工具\.venv\Scripts\python.exe`
   - 引數：`jackbot.py position_change`（另兩個工作改為 `hyperliquid`、`crit_radar`）
   - 開始於：`C:\Path\To\加密貨幣推播工具`

## 環境變數

工作排程器預設**不會**讀你登入後的 PowerShell 環境。請擇一：

- 在「一般」→「設定」裡使用「以最高權限執行」並在系統「環境變數」中設定 `TG_TOKEN`、`CHAT_ID`、`CG_API_KEY` 等；或
- 使用下面 `run-one.bat`，在 bat 內先 `set` 必要變數（不要將含密碼的 bat 上傳雲端）。
